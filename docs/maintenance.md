# Maintenance

## Overview

Regular maintenance improves reliability and extends the service life of the Eco Robot ER-10.

---

## Daily Maintenance

- Inspect the robot for visible damage.
- Clean dust from external surfaces.
- Verify Emergency Stop operation.
- Check indicator lights.

---

## Weekly Maintenance

- Inspect cables for wear.
- Check mounting bolts.
- Verify safety guards.
- Test robot movement.

---

## Monthly Maintenance

- Lubricate moving components (if applicable).
- Inspect electrical connections.
- Review controller logs.
- Back up robot configuration.

---

## Maintenance Checklist

| Task | Frequency |
|------|-----------|
| Visual Inspection | Daily |
| Clean Robot | Daily |
| Cable Inspection | Weekly |
| Bolt Inspection | Weekly |
| System Backup | Monthly |

---

!!! caution "Power Isolation"

    Disconnect electrical power before performing maintenance.
