# Installation Guide

## Overview

This guide explains how to install and prepare the Eco Robot ER-10 for first-time operation.

Complete all installation steps before attempting to power on the robot.

---

## Before You Begin

Verify that you have the following:

| Item | Quantity |
|------|---------:|
| Eco Robot ER-10 | 1 |
| Robot Controller | 1 |
| Power Cable | 1 |
| Ethernet Cable | 1 |
| Mounting Bolts | 4 |
| Installation Manual | 1 |

---

!!! note "Installation Environment"

    Install the robot on a stable, level surface with sufficient clearance for safe robot movement.

---

## Step 1 – Unpack the Robot

1. Carefully remove the robot and accessories from the shipping crate.
2. Inspect all components for visible shipping damage.
3. Verify that all supplied components are present.

---

## Step 2 – Mount the Robot

1. Position the robot on the mounting surface.
2. Align the mounting holes with the workbench.
3. Secure the robot using the supplied mounting bolts.
4. Tighten all bolts to the recommended torque specification.

---

!!! warning "Crushing Hazard"

    The Eco Robot ER-10 weighs approximately 35 kg. Use appropriate lifting equipment or two people when moving the robot.

---

## Step 3 – Connect Power

1. Verify that the main power switch is OFF.
2. Connect the power cable to the controller.
3. Connect the controller to the power outlet.
4. Verify that all cables are securely connected.

---

## Step 4 – Connect the Network

1. Connect the Ethernet cable between the controller and the local network.
2. Verify that the network indicator LED is illuminated.
3. Confirm network connectivity using the controller diagnostics.

---

## Step 5 – Connect the Robot

1. Connect the robot communication cable to the controller.
2. Tighten all connector locking rings.
3. Verify that all connectors are fully seated.

---

## Step 6 – Perform an Initial Inspection

Before applying power, verify:

- The robot is securely mounted.
- All electrical connections are complete.
- Network cables are connected.
- No tools remain inside the work area.
- Emergency Stop buttons are accessible.

---

## Installation Complete

The Eco Robot ER-10 is now installed and ready for first-time startup.

Continue to the **First Startup** guide.
