# Robot Operation

## Overview

This guide explains the basic operation of the Eco Robot ER-10 after installation and startup.

Operators should complete the Safety, Installation, and First Startup procedures before operating the robot.

---

## Operating Modes

The Eco Robot ER-10 supports three operating modes.

| Mode | Description |
|------|-------------|
| Manual | Used for teaching positions and maintenance. |
| Automatic | Executes programmed robot jobs. |
| Maintenance | Used for diagnostics and servicing. |

---

## Starting Automatic Operation

1. Verify that all safety guards are closed.
2. Confirm that no personnel are inside the robot work cell.
3. Verify that the robot status is **Ready**.
4. Select **Automatic Mode**.
5. Press **Start Job**.

The robot begins executing the selected program.

---

!!! warning "Automatic Robot Motion"

    The robot may begin moving immediately after the job starts. Stay outside the safety perimeter during operation.

---

## Pausing a Job

To temporarily stop the robot:

1. Select **Pause**.
2. Wait until robot motion stops.
3. Verify that the robot status changes to **Paused**.

To continue operation:

1. Select **Resume**.

The robot continues from its previous position.

---

## Stopping a Job

To stop the current robot program:

1. Select **Stop Job**.
2. Wait until all robot motion has stopped.
3. Verify that the robot status displays **Stopped**.

---

## Monitoring Robot Status

The Dashboard displays the following information.

| Indicator | Description |
|-----------|-------------|
| Ready | Robot is available for operation |
| Running | Robot is executing a job |
| Paused | Operation has been paused |
| Alarm | Operator action is required |
| Offline | Robot communication has been lost |

---

## Emergency Stop

If an emergency occurs:

1. Press the Emergency Stop button immediately.
2. Wait until all robot motion stops.
3. Notify the supervisor.
4. Investigate the cause before restarting the robot.

---

!!! danger "Emergency Situation"

    Never attempt to enter the robot work cell while the robot is moving. Always use the Emergency Stop button if immediate shutdown is required.

---

## Best Practices

- Inspect the robot before every shift.
- Keep the work area clean.
- Monitor dashboard alerts.
- Never bypass safety devices.
- Stop operation immediately if abnormal movement occurs.
